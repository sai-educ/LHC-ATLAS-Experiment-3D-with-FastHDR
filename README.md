## Overview
A cutting-edge educational simulation that brings particle physics to life through real-time 3D visualization of proton-proton collisions at 14 TeV. Built with modern Three.js and FastHDR rendering techniques, this web-based application provides an accurate, interactive representation of how subatomic particles behave in the world's most powerful particle detector.
Key Features

## Realistic Beam Collision: Watch proton beams travel from opposite directions and collide at the center
Accurate Particle Physics: Different particle types (photons, electrons, muons, hadrons, neutrinos) with proper trajectories and detector interactions
Magnetic Field Simulation: Charged particles curve realistically in the 2 Tesla magnetic field
Layer-Specific Detection: Particles penetrate to different detector depths based on real physics
HDR Rendering Pipeline: Professional-grade visuals with bloom effects and PBR materials
Real-time Interaction: Orbit controls, adjustable parameters, and on-demand collision events

## Running locally
Just open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge), straight from disk or from a web server. Everything it needs is prebuilt into `dist/app.js`.

## Developing
The source lives in `src/` as ES modules and is bundled with esbuild:

```bash
npm install      # once: installs esbuild and three (dev only)
npm run dev      # live-rebuilding server at http://localhost:8000
npm run build    # writes the minified dist/app.js
npm test         # unit tests (Node's built-in runner)
```

**Run `npm run build` and commit `dist/app.js` whenever you change `src/`.** That file is what the page loads, both locally and on Vercel.

### Adjusting the opening camera view
Edit `DEFAULT_VIEW` in `src/config.js`: `direction` sets the viewing angle and `padding` sets how far away the camera sits (smaller is closer). The camera fits the whole detector to any screen size; press **R** or use *Reset View* to return to it.

## Deployment
`vercel.json` deploys the repository as a static site: no install, no build, just the committed files. Push to `main` and Vercel serves `index.html` plus `dist/app.js`.

## Project structure

```
index.html              Page markup: overlay and legend; loads dist/app.js
css/styles.css          All styling
dist/app.js             Bundled app (generated by npm run build; committed)
src/
  main.js               Entry point: wires everything and runs the render loop
  config.js             Tunable params, detector geometry, timing constants
  simulation.js         Beams → collision → outgoing particles lifecycle
  physics/              Pure logic, no Three.js (unit-tested)
    particleTypes.js    Particle species and their detector behaviour
    lorentz.js          Lorentz-force kick in the solenoid field
    absorption.js       Which layer stops which particle
    collisionEvent.js   Monte-Carlo event generation and MET
  entities/             Particle and BeamParticle scene objects
  detector/             Static detector model (barrel, end-caps, toroids, casing)
  effects/              Showers, collision flash, MET arrow, particle traces
  scene/stage.js        Camera, renderer, bloom pipeline, controls, lights
  scene/framing.js      Fits the camera to the detector on any screen shape
  ui/                   HUD overlay and lil-gui control panel
tests/                  node:test unit tests for physics and framing
```
